# Landing Page - The Odin Project

## 📄 Sobre o Projeto
Este repositório contém o código do projeto "Landing Page" (Página de Destino), desenvolvido como parte do currículo *Foundations* do The Odin Project. O objetivo principal desta atividade foi criar uma página web completa do zero, orientando-se por uma imagem de design de referência fornecida.

## 🎯 Estrutura e Funcionalidades
O layout do projeto foi construído e dividido em 4 seções principais, além de um rodapé:
* **Header e Hero Section:** Fundo escuro apresentando o logotipo, links de navegação e a chamada principal do site.
* **Informações:** Exibição de conteúdo secundário alinhado.
* **Citação (Quote):** Área com fundo claro, fonte mais leve e em itálico para destacar uma citação.
* **Call to Action (Chamada para ação):** Um bloco com botão para incentivar a interação do usuário.
* **Footer:** Rodapé padrão do site.

*(Nota: Conforme os requisitos do projeto, o foco foi na estruturação e no posicionamento inicial, não sendo exigido que o layout fosse responsivo para dispositivos móveis nesta etapa*

## 🛠️ Tecnologias Utilizadas
* **HTML:** Organização e inserção de todo o conteúdo na página antes da aplicação de estilos.
* **CSS:** Estilização focada no uso de Flexbox para alinhar, crescer e encolher os elementos adequadamente.
* **Design:** Aplicação de tipografia específica utilizando a fonte *Roboto*, além de uma paleta de cores definida.

## 💡 Aprendizados
Durante o desenvolvimento, as principais práticas exercitadas foram:
* Conversão de um mockup de design visual em código funcional.
* Posicionamento de elementos e distanciamentos usando CSS Flexbox.
* Adição e formatação de fontes e imagens na web.
